# HayaKoh_special-color-replacer
特殊色置換ツール
作成者：林田光惺（HayaKoh）

## 概要
[Simutrans](https://www.simutrans.com/ja/)におけるアドオン制作の補助ツールです。
特殊な色を置き換えたり夜の見た目を確認したりできます。
[WebSim](https://websim.com/)を用いて作成し、いくつかの箇所を手動で編集しました。

## 仕様
いくつかの項目が設定できます。
### 画像を読み込む
画像ファイルをここから読み込みます。
中央のプレビュー画面にドラッグ＆ドロップした場合でも画像を読み込むことができます。

### 消去する色
特殊な色の一覧です。
各色のトグルをONにすることで指定した色の部分が少し暗くなり、特殊な色ではなくなります。
中央のプレビュー画面には変更後の見た目が表示されます。

### 置き換える場所をハイライト
特殊な色のうち暗い色に置き換えたドットを赤紫色で表示します。
なお、ここで表示する赤紫色のドットはダウンロードされる画像に影響しません。

### 背景を透過
`#E7FFFF`（薄い水色）の部分を透明色に変更します。
特殊色の消去よりも優先されるため、「消去する色」で`#E7FFFF`が有効になっている場合も透明色に変更されます。

### 夜景モード
ゲーム内で夜になった場合のグラフィックが確認できます。
なお、ここでの表示はダウンロードされる画像に影響しません。

### 画像を出力
選択した特殊な色が消去された画像をダウンロードします。
`{元のファイル名}_color-replaced.{拡張子}`というファイル名でダウンロードされます。
